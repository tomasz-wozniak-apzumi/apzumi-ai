# Documentation

## glossary.md

`glossary.md` is an **example** glossary of terms. It provides a template for defining project-specific terminology, acronyms, and abbreviations in a centralized place.

**This file is not meant to be used as-is.** Replace the example entries with the terms actually used in your project, and keep it updated as the project evolves. A well-maintained glossary helps AI to understand your prompts better.

## adr/

`adr/` contains Architecture Decision Records (ADRs) documenting significant technical decisions — architectural choices, technology selections, integration patterns, and other non-trivial trade-offs that would otherwise be surprising without context. See `adr/README.md` for the template and guidelines on when to write an ADR.
